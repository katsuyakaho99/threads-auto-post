# 請求書テンプレート

繰り返し使える請求書（インボイス対応）のテンプレートです。

## ファイル

- `invoice_template.xlsx` … 請求書テンプレート本体（Excel / Googleスプレッドシートで開けます）
- `generate_invoice_template.py` … テンプレートを再生成するスクリプト（`openpyxl` を使用）

## 使い方

Excel を持っていなくても、Google スプレッドシートで開いて編集できます。

1. `invoice_template.xlsx` を Google ドライブにアップロード
2. ファイルをダブルクリックして「Google スプレッドシートで開く」

### 入力する場所

**黄色のセル**に入力してください。以下は自動計算されます。

- 各行の **金額** = 数量 × 単価
- **小計** = 各行の金額の合計
- **消費税** = 小計 × 消費税率（初期値 10%）
- **合計（税込）** = 小計 + 消費税 − 源泉徴収税額

主な入力項目:

- 請求書番号 / 請求日 / 支払期限
- 請求先（会社名・住所）
- 発行者（会社名・住所・連絡先・登録番号 `T…`）
- 明細（品目・数量・単価）
- 消費税率 / 源泉徴収税額（任意）
- お振込先 / 備考

初期状態では、記入例として「Webサイト制作 一式 ¥200,000」が入っています。上書きしてご利用ください。

## 再生成

```bash
pip install openpyxl
python generate_invoice_template.py
```

`invoice_template.xlsx` が再生成されます。数式はそのまま保持され、Google スプレッドシート／Excel を開いたときに再計算されます。
